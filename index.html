🔐 Database & Auth Architecture
Current setup: Credentials are stored in your browser's localStorage — private, device-only, no server involved. This means no central user tracking and no email OTP is possible without a backend.

To add email OTP + user analytics: Integrate Supabase (free tier: 50,000 users, built-in email OTP, row-level security). Replace the localStorage auth with Supabase Auth — users get magic-link login, no passwords. Then log search queries, tool clicks and cert clicks to a Supabase analytics table for real subscriber tracking.
